## 项目简介

个人数据隐私授权与访问审计平台面向个人信息保护和合规审计场景，围绕数据主体、个人数据项、授权目的、授权策略、授权记录、访问申请、授权撤销、风险预警和审计报告构建闭环管理能力。

## 角色权限

系统支持 **4** 种角色，各角色权限如下：

### - 管理员

- 维护账号
- 数据主体
- 数据项和操作日志

### - 隐私官

- 维护授权目的
- 授权策略
- 风险预警和审计报告

### - 数据使用人

- 提交访问申请并在授权范围内访问数据

### - 审计员

- 复核访问日志
- 撤销申请和审计报告

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`110-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 110-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 110-frontend
npm install
npm run dev
```
