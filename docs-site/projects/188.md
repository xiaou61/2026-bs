## 项目简介

本系统面向医院护理部、带教老师、考核老师与护理人员的培训管理场景，提供培训项目、护理人员档案、培训班次、培训签到、技能项目、技能考核、证书档案、续训提醒、实操记录、考核申诉和培训通知的一体化管理能力。

## 角色权限

系统支持 **6** 种角色，各角色权限如下：

### - 系统管理员

- 账号权限
- 基础配置和全部数据维护

### - 护理培训管理员

- 维护培训项目
- 培训班次
- 技能项目和培训通知

### - 带教老师

- 组织班次培训
- 登记签到
- 维护实操记录和指导结果

### - 考核老师

- 维护技能考核
- 评分记录
- 申诉处理和考核结论

### - 护理人员

- 查看培训班次
- 完成签到
- 参与考核
- 查看证书和续训提醒

### - 护理人事

- 维护护理人员档案
- 证书档案和续训周期

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`188-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 188-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 188-frontend
npm install
npm run dev
```
