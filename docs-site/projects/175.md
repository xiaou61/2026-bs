## 项目简介

本系统面向校园图书漂流、学生借阅、读书打卡、笔记沉淀、积分勋章和阅读活动场景，提供漂流书架、漂流图书、读者档案、图书捐赠、借阅记录、归还流转、读书打卡、读书笔记、积分勋章、阅读活动和消息通知的一体化后台管理能力。

## 角色权限

系统支持 **6** 种角色，各角色权限如下：

### - 系统管理员

- 账号权限
- 基础配置和全部数据维护

### - 图书馆管理员

- 维护漂流书架
- 漂流图书
- 借阅记录和统计规则

### - 漂流负责人

- 维护图书捐赠
- 借阅记录
- 归还流转和消息通知

### - 学生读者

- 参与图书捐赠
- 图书借阅
- 归还流转
- 读书打卡和读书笔记

### - 读书社团

- 组织阅读活动
- 协同打卡运营和积分勋章评定

### - 阅读指导老师

- 审核读书笔记
- 指导阅读活动
- 评定积分勋章和读者成长

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`175-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 175-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 175-frontend
npm install
npm run dev
```
