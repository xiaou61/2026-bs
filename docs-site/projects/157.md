## 项目简介

本系统面向物流园区车辆入场与月台调度场景，提供承运商预约、车辆档案、司机档案、时段计划、门岗核验、排队叫号、道口资源、道口分配、装卸任务和周转统计的一体化后台管理能力。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`157-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 157-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 157-frontend
npm install
npm run dev
```
