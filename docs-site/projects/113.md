## 项目简介

区块链农产品质量溯源与监管平台面向农产品从生产、质检、上链、仓储、物流、销售到监管抽查的全过程管理，围绕产品批次、种植记录、农资投入、质检报告、区块存证、流通节点、召回事件和监管检查形成可追溯闭环。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`113-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 113-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 113-frontend
npm install
npm run dev
```
