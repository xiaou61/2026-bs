## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | H2 内存模式（默认） |
| Node.js | 以 package.json 为准 |

### 后端启动

默认配置使用 H2 内存数据库，通常无需预先创建外部数据库。

```bash
cd 026-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 026-frontend
npm install
npm run dev
```
