## 项目简介

### 项目简介
孩童收养信息管理系统面向儿童福利机构与社会申请人场景，提供儿童档案管理、收养申请、资格审核、家访评估、匹配审批、协议签订、回访跟踪和公告展示等功能，形成从信息发布到收养后回访的完整业务闭环。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | H2 内存模式（默认） |
| Node.js | 以 package.json 为准 |

### 后端启动

默认配置使用 H2 内存数据库，通常无需预先创建外部数据库。 如需切换外部数据库，请先查看 `088-backend/sql/init.sql`。

```bash
cd 088-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 088-frontend
npm install
npm run dev
```
