## 项目简介

本项目是基于 Spring Boot 3.2、MyBatis-Plus、Spring Security、JWT 的特色民宿预订平台后端，提供用户登录注册、民宿浏览搜索、房型查看、收藏、预订、房东民宿管理和房东订单确认等核心接口。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 以 pom.xml 为准 |
| Maven | 3.8+ |
| 数据库 | H2 内存模式（默认） |
| Node.js | 以 package.json 为准 |

### 后端启动

默认配置使用 H2 内存数据库，通常无需预先创建外部数据库。 如需切换外部数据库，请先查看 `044-backend/sql/init.sql`。

```bash
cd 044-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 044-frontend
npm install
npm run dev
```
