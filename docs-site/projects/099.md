## 项目简介

AIGC 图片内容审核与版权存证平台面向 AI 图片生成、设计素材管理和版权确权场景，提供图片作品入库、内容审核、风险标签、版权登记、存证编号、授权记录、申诉处理和审计统计能力。系统帮助平台方对 AIGC 图片进行合规审核、版权归属登记和后续争议处理。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`099-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 099-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 099-frontend
npm install
npm run dev
```
