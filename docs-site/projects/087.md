## 项目简介

### 项目简介
课程管理系统面向高校教务与教学场景，支持管理员、教师、学生三角色协同完成组织管理、课程开设、排课选课、课程资源、考勤登记、成绩录入、评教反馈和统计分析，形成完整的教学管理闭环。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | H2 内存模式（默认） |
| Node.js | 以 package.json 为准 |

### 后端启动

默认配置使用 H2 内存数据库，通常无需预先创建外部数据库。 如需切换外部数据库，请先查看 `087-backend/sql/init.sql`。

```bash
cd 087-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 087-frontend
npm install
npm run dev
```
