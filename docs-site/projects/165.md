## 项目简介

本系统面向企业园区访客接待与安防门禁场景，提供楼宇区域、被访员工、访客档案、访客预约、访问审批、二维码通行、门禁设备、门禁联动、入园登记、轨迹留痕和异常告警的一体化后台管理能力。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`165-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 165-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 165-frontend
npm install
npm run dev
```
