## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 以 pom.xml 为准 |
| Maven | 3.8+ |
| 数据库 | H2 内存模式（默认） |
| Node.js | 以 package.json 为准 |

### 后端启动

默认配置使用 H2 内存数据库，通常无需预先创建外部数据库。

```bash
cd 049-backend
mvn spring-boot:run
```

### 小程序启动

1. 使用微信开发者工具打开对应的小程序目录
2. 确认 AppID 配置正确
3. 修改后端接口地址（通常在 config.js 或 utils/request.js 中）
4. 点击编译运行
