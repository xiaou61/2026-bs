## 项目简介

本项目面向企业客服中心和在线服务团队，提供客户档案、服务渠道、知识库、客服工单、会话消息、派单记录、质检规则、质检任务、质检结果、知识推荐、坐席绩效和操作审计能力。系统采用 Spring Boot + MyBatis-Plus + MySQL + Redis + Vue3 技术栈，围绕“客户建档-工单受理-会话记录-质检任务-结果复核-知识推荐-绩效统计”形成闭环。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`103-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 103-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 103-frontend
npm install
npm run dev
```
