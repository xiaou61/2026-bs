## 项目简介

在线考试反作弊行为分析与证据管理系统面向毕业设计答辩场景，提供多角色登录、业务台账维护、审批状态流转、统计看板和操作留痕能力。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`138-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 138-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 138-frontend
npm install
npm run dev
```
