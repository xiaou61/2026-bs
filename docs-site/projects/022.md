## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 以 pom.xml 为准 |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`022-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 022-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 022-frontend
npm install
npm run dev
```

### 默认账号

### 开发注意事项

1. 数据库配置：修改 `application.yml` 中的数据库连接信息（数据库名：`study_room`）
2. 后端启动前需先创建数据库并执行 SQL 初始化脚本
2. 后端默认端口为 `8080`，前端代理需配置对应端口
3. 默认账号密码请查看上方表格，首次登录后建议修改密码
