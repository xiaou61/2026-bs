## 项目简介

本系统面向医疗废弃物分类收集、转运交接与处置监管场景，提供医废来源、废物类别、包装赋码、收集预约、称重记录、暂存交接、转运联单、运输轨迹、处置确认、异常追溯和监管抽查的一体化后台管理能力。

## 角色权限

系统支持 **6** 种角色，各角色权限如下：

### - 系统管理员

- 账号权限
- 基础配置和全部数据维护

### - 医院交接员

- 医废来源
- 包装赋码
- 暂存交接和院内出库维护

### - 收运调度员

- 收集预约
- 称重记录
- 暂存交接和转运联单调度

### - 转运司机

- 转运联单
- 运输轨迹
- 车辆交接和异常上报维护

### - 处置厂审核员

- 处置确认
- 入厂复核
- 处置批次和闭环回执维护

### - 监管人员

- 监管抽查
- 异常追溯
- 联单链路和闭环报表查看

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`159-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 159-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 159-frontend
npm install
npm run dev
```
