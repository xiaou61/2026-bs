## 项目简介

本系统面向高校毕业去向填报、就业材料审核、岗位推荐、就业帮扶、协议归档和跟踪回访场景，提供学院专业、毕业生档案、用人单位、招聘岗位、去向填报、协议归档、材料审核、帮扶记录、岗位推荐、跟踪回访和就业统计的一体化后台管理能力。

## 角色权限

系统支持 **6** 种角色，各角色权限如下：

### - 系统管理员

- 账号权限
- 基础配置和全部数据维护

### - 就业中心

- 维护去向填报
- 材料审核
- 就业统计和就业服务规则

### - 学院就业老师

- 维护学院专业
- 毕业生档案
- 协议归档和统计汇总

### - 辅导员

- 维护毕业生档案
- 帮扶记录
- 岗位推荐和跟踪回访

### - 毕业生

- 提交去向填报
- 查看岗位推荐
- 协议归档和帮扶进度

### - 用人单位

- 维护单位档案
- 发布招聘岗位并协同就业推荐

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`173-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 173-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 173-frontend
npm install
npm run dev
```
