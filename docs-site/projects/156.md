## 项目简介

本系统面向高校宿舍能源管理场景，提供宿舍楼栋、宿舍房间、能耗表计、用电读数、能耗账单、预警策略、异常预警、节能任务、节能排行和巡查记录的一体化后台管理能力。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`156-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 156-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 156-frontend
npm install
npm run dev
```
