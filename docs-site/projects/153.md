## 项目简介

本系统面向校园二手物品交易场景，提供寄卖上架、上架审核、担保订单、支付交接、信用评价、违约记录和纠纷申诉的一体化后台管理能力。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`153-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 153-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 153-frontend
npm install
npm run dev
```
