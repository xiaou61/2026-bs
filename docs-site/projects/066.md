## 项目简介

本项目是精简博客系统后端服务，配套 `066-frontend` 使用。系统覆盖登录注册、用户管理、文章分类、标签、文章发布与置顶、评论审核、公告和后台看板等博客核心流程。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | H2 内存模式（默认） |
| Node.js | 以 package.json 为准 |

### 后端启动

默认配置使用 H2 内存数据库，通常无需预先创建外部数据库。 如需切换外部数据库，请先查看 `066-backend/sql/init.sql`。

```bash
cd 066-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 066-frontend
npm install
npm run dev
```
