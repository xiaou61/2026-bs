## 项目简介

本系统面向便民服务中心、办事窗口、材料审核人员、督办人员和办事群众，提供事项档案、窗口档案、人员排班、事项预约、窗口叫号、材料审核、办理进度、通知提醒、满意评价、投诉处理、绩效统计和操作日志的一体化服务管理能力。

## 角色权限

系统支持 **6** 种角色，各角色权限如下：

### - 系统管理员

- 账号权限
- 基础配置和全部数据维护

### - 中心管理员

- 维护事项档案
- 窗口档案
- 排班规则和窗口服务规则

### - 窗口经办

- 处理窗口叫号
- 材料流转
- 办理进度和通知提醒

### - 材料审核

- 审核预约材料
- 反馈审核意见并推动办理流转

### - 督办人员

- 查看满意评价
- 投诉处理和绩效统计

### - 办事群众

- 提交事项预约
- 查看叫号进度
- 办理状态并完成评价

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`195-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 195-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 195-frontend
npm install
npm run dev
```
