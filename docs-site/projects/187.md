## 项目简介

本系统面向旅行社团建行程组织、成员报名确认、预算编制、费用分摊、缴费记录、通知同步和出行反馈场景，提供旅行社档案、团队档案、团建行程、行程报名、成员确认、费用预算、费用分摊、缴费记录、通知同步、出行反馈和发票记录的一体化后台管理能力。

## 角色权限

系统支持 **6** 种角色，各角色权限如下：

### - 系统管理员

- 账号权限
- 基础配置和全部数据维护

### - 旅行社管理员

- 维护旅行社档案
- 团队档案
- 行程规则和协作配置

### - 行程策划

- 编排团建行程
- 预算项目和报名节奏

### - 财务人员

- 维护费用预算
- 费用分摊
- 缴费记录和发票记录

### - 团队领队

- 组织成员报名确认
- 通知同步和出行反馈

### - 团建成员

- 查看行程安排
- 确认报名
- 缴费和提交反馈

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`187-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 187-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 187-frontend
npm install
npm run dev
```
