- Spring Boot 2.7.18
- MyBatis 2.3.1 注解 SQL
- PageHelper 1.4.7
- MySQL 8.0
- Redis 登录态缓存
- JWT 认证

- Vite 5

- ECharts 5.4.3

## 角色权限

系统支持 **4** 种角色，各角色权限如下：

### 管理员

- 维护账号权限
- 仓库基础资料和系统配置。

### 调度员

- 派发AGV任务
- 选择路径并处理异常告警。

### 仓管员

- 维护库存物料
- 入库订单
- 出库订单和库位状态。

### 维保员

- 处理AGV车辆
- 充电站和传感器维保任务。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`118-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 118-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 118-frontend
npm install
npm run dev
```
