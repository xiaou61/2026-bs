## 项目简介

本系统面向生鲜零售门店的临期商品治理场景，提供门店档案、供应商档案、生鲜品类、商品批次、保质期规则、临期预警、促销策略、折扣执行、报损记录、库存周转和门店分析的一体化后台管理能力。

- 门店档案
- 商品批次

### - 理货员

- 商品批次

### - 库存主管

- 生鲜品类
- 保质期规则
- 临期预警
- 报损记录和库存周转维护

### - 促销专员

- 促销策略

- 供应商档案和供货批次状态协同维护

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`162-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 162-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 162-frontend
npm install
npm run dev
```
