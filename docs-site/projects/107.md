## 项目简介

本系统面向云服务器运维监控场景，围绕云区域、主机资产、指标定义、指标采样、告警规则、告警事件、通知记录、处置工单、维护窗口和容量规划构建监控闭环。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`107-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 107-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 107-frontend
npm install
npm run dev
```
