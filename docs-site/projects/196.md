## 项目简介

本系统面向连锁药店、药师审核人员、门店店员、随访专员和慢病顾客，提供药店门店、顾客档案、药品目录、处方登记、处方审核、风险复核、购药记录、用药指导、慢病方案、续方提醒、随访记录和操作日志的一体化管理能力。

## 角色权限

系统支持 **6** 种角色，各角色权限如下：

### - 系统管理员

- 账号权限
- 基础配置和全部数据维护

### - 药店管理员

- 维护门店
- 药品目录
- 慢病服务规则和人员协作权限

### - 药师审核

- 审核处方
- 处理风险复核并记录用药指导

### - 门店店员

- 登记处方
- 维护购药记录并协助顾客完成取药流程

### - 随访专员

- 维护慢病方案
- 续方提醒和随访记录

### - 慢病顾客

- 查看个人处方
- 购药记录
- 用药指导和续方提醒

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`196-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 196-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 196-frontend
npm install
npm run dev
```
