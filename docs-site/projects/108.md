## 项目简介

云原生成本分析与资源优化平台面向企业云资源 FinOps 治理场景，围绕云账号、资源空间、账单明细、预算策略、成本分摊、闲置识别、优化建议、节省计划和异常事件构建闭环管理能力，帮助运维和成本团队完成成本透明、责任分摊、异常发现和优化执行。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`108-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 108-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 108-frontend
npm install
npm run dev
```
