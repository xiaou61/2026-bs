## 项目简介

本项目面向律师事务所、法律咨询机构和高校法律援助中心，提供委托人档案、律师档案、案件台账、咨询记录、案件进度、证据材料、文书模板、智能文书、版本留痕、预约咨询、费用记录和审计统计能力。系统采用 Spring Boot + MyBatis + MySQL + Redis + Vue3 技术栈，围绕“咨询建档-案件分配-进度跟踪-证据归档-文书生成-预约沟通-费用结算-审计留痕”形成闭环。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`102-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 102-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 102-frontend
npm install
npm run dev
```
