## 项目简介

面向本地生活平台、商户门店、收银员和财务人员，覆盖服务券模板、营销活动、用户领券、到店核销、商户结算、打款记录、申诉处理和活动统计。

## 角色权限

系统支持 **4** 种角色，各角色权限如下：

### 管理员

- 维护账号权限
- 商户资料
- 门店和活动配置。

### 商户

- 查看门店核销
- 结算单和打款记录。

### 收银员

- 执行到店券码核销和撤销操作。

### 财务

- 核算结算单
- 确认明细并执行商户打款。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`117-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 117-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 117-frontend
npm install
npm run dev
```
