## 项目简介

本系统面向景区游客失物登记、拾物上报、身份核验与寻回协同场景，提供景区区域、失物登记、拾物上报、游客认领、身份核验、位置追踪、暂存保管、通知协同、归还交接、寻回任务和回访评价的一体化后台管理能力。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`161-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 161-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 161-frontend
npm install
npm run dev
```
