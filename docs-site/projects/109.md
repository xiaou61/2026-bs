## 项目简介

数据脱敏与敏感信息识别平台面向企业数据安全治理场景，围绕数据源接入、数据集目录、敏感规则、识别任务、识别结果、脱敏策略、脱敏任务、访问申请、导出审批和风险告警构建完整闭环，帮助企业降低敏感数据泄露风险。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`109-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 109-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 109-frontend
npm install
npm run dev
```
