## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |

### 后端启动

请先查看项目配置文件中的数据库 profile 和初始化方式。

```bash
cd 015-backend
mvn spring-boot:run
```

### 默认账号

| 角色 | 用户名 | 密码 | 说明 |
|------|--------|------|------|
| 管理员 | `admin` | `admin123` |  |

### 开发注意事项

1. 数据库配置：修改 `application.yml` 中的数据库连接信息（数据库名：`campus_confession`）
2. 后端启动前需先创建数据库并执行 SQL 初始化脚本
2. 后端默认端口为 `8080`，前端代理需配置对应端口
3. 默认账号密码请查看上方表格，首次登录后建议修改密码
