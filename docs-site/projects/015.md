## 项目简介

这是一个基于Spring Boot 3的校园表白墙与匿名社交平台，提供匿名发帖、评论互动、点赞、私信等功能，内置敏感词过滤和举报审核机制。

## 角色权限

系统支持 **2** 种角色，各角色权限如下：

### 用户

- 用户注册/登录（实名认证）
- 匿名发帖（表白/吐槽/求助/树洞/校园/闲聊）
- 话题广场（分类浏览、热门/最新排序）
- 帖子详情（浏览、点赞、评论）
- 评论互动（楼中楼）
- 敏感词自动过滤
- 私信功能（匿名对话）
- 举报功能（举报帖子/评论）
- ...还有 3 项权限

### 管理

- 数据概览统计
- 用户管理（禁言/封号）
- 实名认证审核
- 帖子内容审核
- 举报处理
- 敏感词管理
- 帖子置顶/删除
