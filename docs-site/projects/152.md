## 项目简介

本系统面向化工、制造、能源等工厂危险作业场景，提供作业票申请、分级审批、安全交底、现场监护、气体检测和隐患整改闭环的一体化后台管理能力。

## 角色权限

系统支持 **5** 种角色，各角色权限如下：

### - 系统管理员

- 账号权限
- 基础配置和全部数据维护

### - 安全主管

- 作业区域
- 风险源台账
- 作业票
- 隐患闭环
- 应急预案和统计看板维护

### - 审批负责人

- 作业票审批
- 审批链路流转和审批意见维护

### - 现场监护人

- 监护安排
- 监护记录
- 气体检测和隐患上报维护

### - 作业申请人

- 作业票申请
- 安全交底确认和整改反馈提交

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`152-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 152-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 152-frontend
npm install
npm run dev
```
