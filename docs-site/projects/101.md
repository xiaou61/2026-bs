## 项目简介

`101-backend` 是 101 号项目的 Spring Boot 后端，提供认证鉴权、候选人档案、简历与证书、岗位与岗位要求、解析任务、匹配任务、面试排期、面试反馈、统计看板和操作日志接口。

**前端：** `101-frontend` 是 101 号项目的 Vue 3 管理端，按角色提供管理员、HR、候选人和面试官四类入口。

## 角色权限

系统支持 **4** 种角色，各角色权限如下：

### - 管理员

- 维护账号
- 首页看板和操作日志

### - HR

- 维护候选人档案
- 简历
- 证书核验
- 岗位
- 岗位要求
- 解析任务
- 解析结果
- 匹配任务
- ...还有 1 项权限

### - 候选人

- 仅维护自己的候选人档案
- 简历和证书材料

### - 面试官

- 仅查看分配给自己的面试排期并填写自己的反馈

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`101-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 101-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 101-frontend
npm install
npm run dev
```
