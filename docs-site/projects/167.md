## 项目简介

本系统面向社区垃圾分类督导与居民积分激励场景，提供社区区域、楼栋档案、居民档案、分类规则、分类打卡、督导记录、整改任务、积分记录、兑换商品、积分兑换和楼栋排名的一体化后台管理能力。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`167-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 167-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 167-frontend
npm install
npm run dev
```
