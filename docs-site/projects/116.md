## 项目简介

面向直播电商运营团队、主播、商家和售后客服，覆盖选品入池、样品寄送、直播排期、话术审核、订单履约、售后工单、退款处理和主播绩效统计。

- 维护账号权限

- 维护供应商品牌
- 配合选品和样品寄送。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`116-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 116-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 116-frontend
npm install
npm run dev
```
