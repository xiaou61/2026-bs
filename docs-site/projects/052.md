## 项目简介

本项目是 `052 网课在线学习观看系统` 的 Spring Boot 后端，提供用户注册登录、课程分类、课程浏览、章节视频、学习进度、收藏评论和管理端统计等接口。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | H2 内存模式（默认） |
| Node.js | 以 package.json 为准 |

### 后端启动

默认配置使用 H2 内存数据库，通常无需预先创建外部数据库。 如需切换外部数据库，请先查看 `052-backend/sql/init.sql`。

```bash
cd 052-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 052-frontend
npm install
npm run dev
```
