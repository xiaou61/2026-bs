## 项目简介

本系统面向博物馆、非遗馆、展览馆等文旅场馆，提供票务预约、讲解排期、扫码核销、客流统计、游客评价和公告发布的一体化后台管理能力。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`151-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 151-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 151-frontend
npm install
npm run dev
```
