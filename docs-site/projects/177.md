## 项目简介

本系统面向直播基地运营、主播排班、商品选品、样品借还、直播计划、直播场次和直播复盘场景，提供直播间档案、主播档案、商家档案、商品选品、样品台账、样品借还、主播排班、选品评测、直播计划、直播场次和直播复盘的一体化后台管理能力。

## 角色权限

系统支持 **6** 种角色，各角色权限如下：

### - 系统管理员

- 账号权限
- 基础配置和全部数据维护

### - 基地运营

- 维护直播间档案
- 主播档案
- 主播排班
- 直播计划和统计规则

### - 主播

- 查看排班
- 参与样品借还
- 执行直播场次并提交直播复盘

### - 选品专员

- 维护商品选品
- 选品评测
- 直播计划和样品协同

### - 样品管理员

- 维护样品台账
- 样品借还
- 样品归还和状态流转

### - 商家代表

- 维护商家档案
- 商品提报
- 样品寄送和直播复盘反馈

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`177-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 177-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 177-frontend
npm install
npm run dev
```
