本系统面向实验动物饲养排班、伦理申请审批、实验登记、健康巡检、异常告警、兽医处置和耗材使用场景，提供动物房间、实验动物档案、饲养排班、饲养记录、伦理申请、伦理审批、实验登记、健康巡检、异常告警、兽医处置和耗材使用的一体化后台管理能力。

## 角色权限

系统支持 **6** 种角色，各角色权限如下：

### - 系统管理员

- 账号权限
- 基础配置和全部数据维护

### - 实验室管理员

- 维护动物房间
- 动物档案
- 实验登记和耗材规则

### - 饲养员

- 查看饲养排班
- 登记饲养记录并上报异常告警

### - 课题研究员

- 提交伦理申请
- 登记实验过程并查看审批结果

### - 伦理委员

- 执行伦理审批
- 复核实验登记和审批留痕

### - 兽医

- 执行健康巡检
- 异常诊断和兽医处置

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`183-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 183-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 183-frontend
npm install
npm run dev
```
