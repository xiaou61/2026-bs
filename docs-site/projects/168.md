## 项目简介

本系统面向职业培训机构与持证人员继续教育场景，提供培训课程、学员档案、讲师档案、课程报名、学习进度、考试安排、考试成绩、证书发放、证书台账、续证申请和提醒通知的一体化后台管理能力。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`168-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 168-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 168-frontend
npm install
npm run dev
```
