## 技术栈

### 后端

- Spring Boot 3.2.0
- MyBatis 3.0.3（区别于MyBatis-Plus，使用原生XML配置）
- MySQL 8.0
- Redis 6.0+
- Spring Security + JWT 0.11.5
- Knife4j 4.3.0（API文档）
- Druid 1.2.20（数据库连接池）
- 微信小程序SDK 4.5.0
- Hutool、Lombok、MapStruct

### 前端

- 微信小程序原生开发（区别于Vue/React Web应用）
- WeUI + Vant Weapp（可选）
- 自定义request封装

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | H2 内存模式（默认） |
| Node.js | 以 package.json 为准 |

### 后端启动

默认配置使用 H2 内存数据库，通常无需预先创建外部数据库。

```bash
cd 037-backend
mvn spring-boot:run
```

### 小程序启动

1. 使用微信开发者工具打开对应的小程序目录
2. 确认 AppID 配置正确
3. 修改后端接口地址（通常在 config.js 或 utils/request.js 中）
4. 点击编译运行
