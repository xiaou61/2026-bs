## 项目简介

城市噪声投诉监测与执法协同平台面向城市噪声治理协同场景，提供多角色登录、投诉受理、执法处置、整改复测、统计看板和操作留痕能力。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`145-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 145-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 145-frontend
npm install
npm run dev
```
