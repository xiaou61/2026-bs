## 项目简介

本系统面向写字楼、园区物业、入驻单位、维修技师与巡检人员的楼宇运维场景，提供楼宇档案、设备档案、入驻档案、访修工单、维修派工、保养计划、保养任务、故障预警、巡检记录、备件库存、服务评价和操作日志的一体化管理能力。

## 角色权限

系统支持 **6** 种角色，各角色权限如下：

### - 系统管理员

- 账号权限
- 基础配置和全部数据维护

### - 物业管理员

- 维护楼宇档案
- 设备档案
- 入驻档案和服务规则

### - 访修调度员

- 处理访修工单
- 维修派工
- 服务评价和跨岗位协同

### - 维修技师

- 接收维修派工
- 执行保养任务并处置故障预警

### - 设备巡检员

- 维护巡检记录
- 上报故障预警并跟进设备状态

### - 入驻用户

- 提交访修工单
- 查看维修进度并完成服务评价

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`190-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 190-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 190-frontend
npm install
npm run dev
```
