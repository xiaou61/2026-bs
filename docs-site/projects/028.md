## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | H2 内存模式（默认） |
| Node.js | 以 package.json 为准 |

### 后端启动

默认配置使用 H2 内存数据库，通常无需预先创建外部数据库。

```bash
cd 028-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 028-frontend
npm install
npm run dev
```

### 默认账号

- 未从项目资料中提取到演示账号，请以项目 README、检查报告或初始化脚本为准。

### 开发注意事项

1. 默认使用 H2 内存数据库，无需预先创建外部数据库
2. 后端默认端口为 `8028`，前端代理需配置对应端口
3. 默认账号密码请查看上方表格，首次登录后建议修改密码
