## 项目简介

零信任设备准入与访问控制管理系统面向企业终端安全和访问控制场景，围绕设备资产、员工账号、身份源、风险评估、访问策略、准入申请、访问会话、设备证书和审计事件构建闭环，确保每一次访问都经过身份、设备和风险校验。

## 角色权限

系统支持 **4** 种角色，各角色权限如下：

### - 管理员

- 维护账号
- 设备资产
- 员工账号和操作日志

### - 安全管理员

- 维护风险模型
- 风险评估
- 访问策略和审计事件

### - 网络管理员

- 维护网络分区
- 设备证书
- 访问会话和准入申请

### - 审计员

- 查看策略命中
- 阻断记录和审计事件

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`112-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 112-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 112-frontend
npm install
npm run dev
```
