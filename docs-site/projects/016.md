## 项目简介

### 1.1 项目背景
校园快递代领服务平台是一个解决大学生取快递痛点的校园服务平台。很多学生因为课程、社团活动等原因无法及时取快递，而快递站点通常距离宿舍较远，取快递耗时耗力。本平台通过"众包代取"模式，让有时间的学生帮助没时间的学生代领快递，同时赚取跑腿费。

### 1.2 项目名称
校园快递代领服务平台（Campus Express Helper）

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 以 pom.xml 为准 |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`016-backend/src/main/resources/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 016-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 016-frontend
npm install
npm run dev
```
