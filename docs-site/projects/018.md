## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 以 pom.xml 为准 |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`018-backend/src/main/resources/schema.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 018-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 018-frontend
npm install
npm run dev
```
