## 项目简介

本系统面向口腔门诊预约、签到分诊、治疗记录、耗材库存、耗材使用和费用结算场景，提供诊室档案、医生档案、患者档案、治疗项目、预约诊疗、签到分诊、治疗记录、耗材目录、耗材库存、耗材使用和费用结算的一体化后台管理能力。

## 角色权限

系统支持 **6** 种角色，各角色权限如下：

### - 系统管理员

- 账号权限
- 基础配置和全部数据维护

### - 前台导诊

- 维护患者档案
- 预约诊疗
- 签到分诊和诊室安排

### - 口腔医生

- 维护医生档案
- 治疗项目
- 治疗记录和耗材使用

### - 诊疗护士

- 协助签到分诊
- 耗材目录
- 耗材库存和耗材使用登记

### - 收费人员

- 维护治疗项目价格
- 耗材计费
- 费用结算和收费状态

### - 患者用户

- 查看预约诊疗
- 治疗记录
- 耗材计费和结算进度

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`172-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 172-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 172-frontend
npm install
npm run dev
```
