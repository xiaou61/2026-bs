## 项目简介

本系统面向高校体育赛事组织与裁判评分场景，提供体育赛事、参赛队伍、运动员档案、赛事报名、报名分组、赛程编排、场地资源、裁判指派、裁判评分、成绩公示和申诉复核的一体化后台管理能力。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`164-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 164-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 164-frontend
npm install
npm run dev
```
