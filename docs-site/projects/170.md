## 项目简介

本系统面向养老机构入住评估、床位分配、护理计划、护理记录、家属查询与异常上报场景，提供护理区域、房间床位、老人档案、家属档案、入住评估、床位分配、护理计划、护理记录、家属查询和异常上报的一体化后台管理能力。

## 角色权限

系统支持 **6** 种角色，各角色权限如下：

### - 系统管理员

- 账号权限
- 基础配置和全部数据维护

### - 入住管理员

- 维护老人档案
- 家属档案
- 入住评估和床位分配

### - 护理主管

- 维护护理区域
- 护理计划
- 护理记录和异常复核

### - 护理人员

- 执行护理计划
- 填写护理记录并上报异常

### - 家属用户

- 查看老人档案
- 护理记录
- 家属查询和异常进度

### - 院长管理员

- 查看全院床位
- 护理
- 异常和运营统计

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`170-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 170-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 170-frontend
npm install
npm run dev
```
