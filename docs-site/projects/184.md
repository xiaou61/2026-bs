## 项目简介

本系统面向停车场月租合同续费、车辆绑定、车位巡检、异常占位、违规处理和客服协同场景，提供停车场档案、车位档案、月租车主、月租合同、续费提醒、续费缴费、车辆绑定、占位巡检、异常占位、违规处理和客服工单的一体化后台管理能力。

## 角色权限

系统支持 **6** 种角色，各角色权限如下：

### - 系统管理员

- 账号权限
- 基础配置和全部数据维护

### - 停车场管理员

- 维护停车场档案
- 车位档案
- 月租合同和车辆绑定

### - 收费财务

- 维护续费提醒
- 续费缴费
- 费用核对和合同续期状态

### - 巡检员

- 执行占位巡检
- 上报异常占位并协同违规处理

### - 月租车主

- 查看合同
- 续费缴费
- 绑定车辆并提交客服工单

### - 客服专员

- 处理续费提醒
- 异常占位沟通和客服工单闭环

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`184-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 184-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 184-frontend
npm install
npm run dev
```
