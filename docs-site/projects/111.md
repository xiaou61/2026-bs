## 项目简介

网络钓鱼邮件演练与安全意识培训平台面向企业安全运营场景，围绕员工档案、邮件模板、演练活动、目标名单、发送记录、点击追踪、培训课程、培训考试和风险评分构建完整闭环，帮助企业提升员工识别钓鱼邮件和保护账号凭据的能力。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`111-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 111-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 111-frontend
npm install
npm run dev
```
