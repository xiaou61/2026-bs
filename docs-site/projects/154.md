## 项目简介

本系统面向宠物医院门诊运营场景，提供宠主建档、宠物档案、医生排班、接诊预约、疫苗计划、接种记录、随访记录和费用结算的一体化后台管理能力。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`154-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 154-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 154-frontend
npm install
npm run dev
```
