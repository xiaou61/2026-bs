## 项目简介

本系统面向社区慢病患者建档、随访计划、服药提醒、健康指标采集、风险分层和依从性管理场景，提供社区站点、患者档案、医护团队、慢病档案、随访计划、随访记录、用药方案、服药打卡、健康指标、风险分层和提醒通知的一体化后台管理能力。

### - 随访护士

- 执行随访记录
- 健康指标采集

### - 用药药师

- 维护用药方案

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`174-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 174-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 174-frontend
npm install
npm run dev
```
