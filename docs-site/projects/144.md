## 项目简介

无障碍出行路线规划与志愿协助平台面向无障碍出行服务协同场景，提供多角色登录、路线规划、协助预约、任务调度、统计看板和操作留痕能力。

## 快速启动

### 环境要求

| 工具 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| 数据库 | MYSQL |
| Node.js | 以 package.json 为准 |

### 后端启动

初始化脚本：`144-backend/sql/init.sql`。执行前请检查脚本是否包含破坏性操作。

```bash
cd 144-backend
mvn spring-boot:run
```

### 前端启动

```bash
cd 144-frontend
npm install
npm run dev
```
